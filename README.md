# Camera808 📸✨

> AI-Powered 9:16 Instagram Story Camera with AR Pose Guidance & Auto-Save.

Camera808 is a modern, ultra-minimalist mobile camera application engineered for capturing perfectly framed portrait and lifestyle photos in native **9:16 Instagram Story format**.

---

## 🌟 Key Features

- **9:16 Instagram Story Mode:** Automatically crops and optimizes every capture to edge-to-edge 9:16 aspect ratio without distortion.
- **AI Composition & Horizon Guidance:** Real-time motion sensor feedback to align your horizon and framing before shooting.
- **Interactive AR Pose Assistant:** Visual silhouette wireframes and photography tips to guide your subjects effortlessly.
- **Seamless Gallery Auto-Save:** Automatically saves photos directly to your Android/iOS camera roll organized in a dedicated `Camera808` album.
- **Dual UI Modes:**
  - **AI Mode:** Ultra-minimalist, distraction-free shooting interface.
  - **PRO Mode:** Real-time hardware HUD showing ISO, shutter speed, focal length, and dynamic scene analysis.
- **Multi-Lens Switcher:** Quick presets for 0.5x Ultra-Wide, 1x Main, 2x Telephoto, and 5x Zoom.
- **One-Tap AI Auto-Adjust:** 3-second smart countdown timer with composition stabilization.

---

## 🛠️ Tech Stack

- **Framework:** React Native / Expo (SDK 57)
- **Camera Engine:** `expo-camera`
- **Image Processing:** `expo-image-manipulator`
- **Media & Gallery:** `expo-media-library`
- **Sensors:** `expo-sensors` (Gyroscope, Accelerometer)
- **Icons:** `lucide-react-native`
- **Language:** TypeScript

## 🚀 Getting Started

### Prerequisites
- Node.js (v20+ recommended)
- Android Studio / Xcode (for native development)
- Expo CLI

### Installation

```bash
# Clone the repository
git clone https://github.com/aj-techsoul/camera808.git
cd camera808

# Install dependencies
npm install

# Start development server
npx expo start

# Run on Android
npx expo run:android

# Run on iOS
npx expo run:ios
```
